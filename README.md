# 📄 ГОСТ Документ Чекер

Автоматическая система проверки и исправления технической документации на соответствие стандартам ГОСТ с использованием Mistral AI.

---

## 🎯 Описание

Инструмент анализирует документы Word (.docx), находит ошибки и несоответствия ГОСТ, автоматически исправляет их и форматирует документ в соответствии с требованиями.

---

## ⚡ Возможности

- 🔍 **Анализ по 5 категориям:**
  - Семантические ошибки
  - Логические противоречия
  - Стилистические нормы
  - Контекстные зависимости
  - Орфографические ошибки

- 🤖 **Двойная проверка ИИ** для повышения точности
- 🔄 **Ротация API ключей** при лимитах
- 📝 **Автоматическое исправление** документа
- 🎨 **Форматирование по ГОСТ** (шрифт, отступы, интервалы)
- 📊 **Статистика использования** ключей

---

## 🚀 Установка и запуск

### 1. Клонирование

```bash
git clone https://github.com/ghostex-cpu/GOST_standards_checker.git
cd GOST_standards_checker
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

или вручную:

```bash
pip install mistralai python-docx requests
```

### 3. Настройка API ключей

Откройте `checker.py` и добавьте свои API ключи:

```python
API_KEYS = [
    "ваш_первый_ключ_mistral",
    "ваш_второй_ключ_mistral",
    # добавьте сколько нужно
]
```

**Где взять ключи:** [Mistral AI Console](https://console.mistral.ai/)

### 4. Подготовка документа

Поместите файл `УПД _не трогать.docx` в папку проекта или измените путь:

```python
doc_path = "путь/к/вашему/документу.docx"
```

### 5. Запуск

```bash
python checker.py
```

## ⚙️ Как это работает

```
1. Извлечение текста из .docx
         ↓
2. Первая проверка (ИИ №1)
         ↓
3. Вторая проверка (ИИ №2)
         ↓
4. Сравнение результатов (ИИ №3)
         ↓
5. Парсинг исправлений
         ↓
6. Автоматическое исправление документа
         ↓
7. Форматирование по ГОСТ
         ↓
8. Сохранение результата
```

---

## 📝 Формат ответа ИИ

```
[Номер параграфа][Тип ошибки] - Исправленный текст
```

**Пример:**
```
[15][Стилистическая норма] - В случае необходимости следует...
[23][Орфографическая ошибка] - Система должна обеспечивать...
```

---

## 🎨 Форматирование по ГОСТ

Автоматически применяются настройки:

- **Шрифт:** Times New Roman, 14pt
- **Межстрочный интервал:** 1.5
- **Отступы:** левый 30мм, правый 15мм, верх/низ 20мм

---

## 🔄 Ротация API ключей

Система автоматически переключает ключи при:
- Исчерпании квоты
- Превышении лимитов (Rate Limit)
- Ошибках авторизации

**Время ожидания:** 2-5 секунд между попытками

---


## ⚠️ Важно

1. **НЕ публикуйте API ключи** в репозитории (используйте `.gitignore`)
2. Убедитесь, что документ в формате `.docx`
3. Интернет-соединение обязательно для работы с API

- Информативные сообщения об ошибках
